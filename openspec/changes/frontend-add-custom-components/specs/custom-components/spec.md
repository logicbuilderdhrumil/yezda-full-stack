## ADDED Requirements
### Requirement: Organization selector
The system SHALL provide a component to select an active organization.

#### Scenario: Select organization
- **WHEN** a user selects an organization from the selector
- **THEN** the active organization context updates

### Requirement: Theme toggle
The system SHALL provide a component to toggle theme mode.

#### Scenario: Toggle theme
- **WHEN** a user switches theme mode
- **THEN** the application theme updates
