## ADDED Requirements
### Requirement: Formatting helpers
The system SHALL provide reusable helpers for common formatting tasks.

#### Scenario: Format date
- **WHEN** a date is displayed
- **THEN** the system formats it using a shared helper

### Requirement: Pagination helpers
The system SHALL provide helpers for pagination and search.

#### Scenario: Paginate results
- **WHEN** a list view paginates data
- **THEN** it uses shared pagination helpers
