## ADDED Requirements
### Requirement: Chat view components
The system SHALL provide components that structure chat views.

#### Scenario: Render chat box
- **WHEN** the chat page renders
- **THEN** it uses a shared chat box layout component

### Requirement: File icon mapping
The system SHALL provide a component that maps file types to icons.

#### Scenario: Display file icon
- **WHEN** a file is displayed in a list
- **THEN** the system shows the appropriate file icon
