# Change: Add app consent-based data reuse

## Why
Candidates need transparent controls to consent to reusing prior application data across screenings.

## What Changes
- Add consent prompt and explanation before reusing prior data.
- Add consent decision capture and review within the app.
- Add consent update and withdrawal handling.

## Impact
- Affected specs: app-consent-reuse
- Affected code: app consent UI, app API client
